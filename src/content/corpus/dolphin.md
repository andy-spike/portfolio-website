# Dolphin

## What Dolphin is

Dolphin is a web app that generates courses. You point it at an online course and it produces a complete, standalone version of that course — readable lessons, exercises, code — generated by a custom agent Andrés built for the job. A front end manages the whole workflow: starting a course, watching it progress, and reviewing the result.

Dolphin began as a terminal app that scraped courses. It is now a web app.

## The problem Dolphin solves

The hard problem is quality. A course is not regular text. It mixes narration, code, exercises, and structure, and the pieces have to hold together as one lesson. That is exactly the kind of task where a deterministic script fails and a raw model call guesses. Dolphin's agent reads the source, plans the lesson, and produces the material. The quality of that output is the product.

## How Dolphin is built

Dolphin is a full-stack TypeScript app organized as a monorepo with Turborepo. A course service on Cloudflare Workers, built with Hono and Drizzle, stores and serves the course state. The front end drives the generation workflow. At the center sits the custom agent that orchestrates the model calls producing the material.

## Decisions and the alternatives rejected

**Decision: agents as the generation engine.** Dolphin generates course material with a custom agent, not a fixed script and not a single raw model call. A script fails because courses are not regular enough for a template to hold. A single model call fails because it cannot read, plan, and rewrite a whole lesson coherently. The agent is the engine, and that is what makes the output usable.

**Decision: web app over terminal app.** Dolphin started as a terminal app. A terminal suits a one-shot scrape, but generation is a workflow: you start a course, watch it progress, and come back to the result. That needs a real interface that manages the job. Andrés tried the terminal first and switched to a web app when it did not fit the workflow.

## What state Dolphin is in

Dolphin is a working web app. Its source is public on GitHub, and it can be run locally.
